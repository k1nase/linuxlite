**Fichiers post-installation pour linux lite et ubuntu mate 26.04**

### Utilisation
1. Télécharger le fichier souhaité
2. Le rendre exécutable (sudo chmod +x)
3. L'exécuter en ligne de commandes (bash 'NOM DU FICHIER')

### Avertissement concernant les fichiers Ubuntu Mate
Les scripts contenant les instructions permettant de "dé-snaper" la distribution Ubuntu Mate sont spécifiques de la version 26.10, sur une installation initiale.
En cas d'utilisation sur une autre version ou sur une installation contenant plus de snaps, adapter les commandes de désinstallation des snaps
